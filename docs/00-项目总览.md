# 小家菜单项目学习库

这是“小家菜单”项目的 Obsidian 笔记库，用于沉淀功能复盘、技术知识、面试题、架构规划和开发记录。

## 当前项目

- 项目名称：小家菜单
- 当前技术：微信原生小程序、微信云开发、云数据库、云函数、云存储
- 当前阶段：家庭版稳定验收完成后，规划多商家架构
- 长期定位：基于微信小程序云开发的多商家餐饮点餐管理系统

## 使用约定

- 每完成一个独立功能，在“功能复盘”创建一篇记录。
- 遇到不熟悉的框架、云函数、数据库或权限知识，在“知识学习”记录。
- 将功能复盘中的高频问题整理到“面试题”。
- 每次重要开发或测试后，在“开发日志”记录日期、改动、验证结果和下一步。

## 学习目标

通过这个项目逐步掌握前端页面开发、微信云开发、云函数鉴权、库存事务、订单状态、数据建模和多租户架构，并能把实践经验转化为简历项目和面试回答。
