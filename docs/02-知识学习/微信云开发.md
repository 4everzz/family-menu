# 微信云开发

## 概念名称

微信云开发。

## 通俗解释

以前做小程序时，开发者需要自己购买服务器、安装数据库、写后端接口。微信云开发把这些基础能力准备好了：小程序可以调用云端代码、保存数据和上传图片。

## 专业表述

微信云开发是一种 Serverless（无服务器运维）开发模式，包含云函数、云数据库、云存储和身份上下文。开发者关注业务代码，平台负责大部分服务器运行和扩缩容工作。

## 在本项目中的位置

- 云数据库保存用户、菜品、分类和订单。
- 云函数处理登录身份、权限、订单、库存、菜品和分类管理。
- 云存储保存菜品图片。

## 企业工作常用场景

云开发适合小程序原型、内部工具、小型业务和快速验证。业务变复杂后，企业可能改用独立后端服务，但云函数中的接口设计和权限思想仍然可以复用。

## 面试常问

**问题：云函数和前端页面分别负责什么？**

**回答思路：** 前端负责界面、输入和展示；云函数负责权限校验、订单创建、库存扣减等关键业务。不能只在前端做权限或库存判断，因为客户端数据不可信。
