# 小家菜单微信小程序

面向家庭及小型餐饮店的微信原生点餐小程序。顾客扫码进入对应店铺或桌位后点餐；店铺管理员在小程序内处理订单、菜单、库存和现场设置；平台超级管理员使用独立 Web 后台管理跨店数据。

当前版本：`v1.1.0`

## 已实现能力

- 微信登录、随机用户 ID、个人资料与店铺角色权限。
- 多店铺数据隔离：菜品、分类、订单、桌位均按 `shopId` 隔离。
- 店铺码、固定桌码与二维码扫码进入；顾客未进入店铺时不能展示菜单或创建订单。
- 菜单、分类、辣度、备注、购物车、图片缓存和每日库存管理。
- 订单状态：`制作中 -> 已完成`，或由店铺管理员取消；取消订单必须记录原因，当天取消恢复库存。
- 云数据库事务库存扣减与下单幂等，降低多人同时下单导致超卖或重复订单的风险。
- 小程序店铺统计和 Web 经营报表只将已完成订单计入营业额。

## 技术组成

- 前端：微信原生小程序 `WXML + WXSS + JavaScript`。
- 服务端：微信云开发云函数，前端统一通过 `wx.cloud.callFunction` 调用。
- 数据：微信云数据库与云存储。菜品图片只存云存储文件 ID，访问链接是临时链接。

## 本地打开

1. 微信开发者工具选择“导入项目”。
2. 项目目录选择本文件夹 `miniprogram`。
3. 确认云开发环境为 `cloud1-d2gua37h7753f3812`。
4. 开发者工具中部署有改动的云函数，再重新编译小程序。

## 发布前必须完成

1. 部署本次修改涉及的云函数，选择正确云环境并在云端安装依赖。
2. 真机或体验版完成顾客、一级管理员、二级管理员、超级管理员的角色测试。
3. 若 Web 后台有前端改动，执行 `web-admin-frontend` 中的 `npm run build`，将 `dist` 覆盖上传到已有静态托管应用。
4. 不要把 AppSecret、管理员密码、令牌或云环境密钥写进小程序代码或 Git 仓库。
