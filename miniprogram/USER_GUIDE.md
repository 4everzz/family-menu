# 小家菜单使用说明

适用对象：到店顾客、家庭成员、店铺管理员。  
当前版本：`v1.1.0`

本小程序用于现场扫码点餐和店铺日常管理。顾客通过店铺码或桌码进入对应店铺；店铺管理员在自己的店铺内处理菜单、库存和订单；跨店铺管理只在 Web 超管后台进行。

## 一、顾客/用户怎么使用

### 1. 第一次打开小程序

1. 打开小程序后，按页面提示完成微信登录和基本资料授权。
2. 未进入店铺时，首页只显示扫码入口，不会展示其他店铺的菜单。
3. 点击首页的“扫码”图标，扫描店铺提供的店铺码或桌码二维码；如页面提供手动输入，也可输入店铺数字码。
4. 扫码成功后会进入对应店铺的点菜页面。不同店铺的数据完全分开，不会看到其他店的菜品或订单。

### 2. 店铺码和桌码有什么区别

- **店铺码**：确认你进入哪一家店，可以先浏览该店菜单和加购。
- **桌码**：确认你坐在哪一桌。店铺设置为堂食桌位模式时，提交订单前必须扫当前桌的桌码。
- 扫到桌码后，菜单顶部会显示“当前桌号：X 号桌”。显示“暂未扫码”时，先扫描桌码再提交订单。

不要扫描别桌的桌码；扫错后重新扫描自己所在桌位即可。切换店铺或桌位时，购物车会清空，避免把上一桌或上一店的菜误下单。

### 3. 点菜和提交订单

1. 在“点菜”页选择分类和菜品。
2. 点击菜品卡片上的加号加入购物车；需要减少数量时点击减号。
3. 进入购物车后，核对菜品、数量、辣度和备注。
4. 辣度由菜品本身决定；特殊需求使用一个普通备注框填写，例如“不要香菜”“少盐”。
5. 确认桌号和金额后提交订单。

下单成功后，订单会进入“制作中”。库存不足、菜品下架、菜品售罄或当天店铺暂停接单时，系统会阻止提交，请按提示处理。

### 4. 查看订单和个人资料

- “订单”页会显示当前制作中的订单，并保留最近完成订单；完整已完成历史在“我的 → 历史订单”中查看。
- 订单状态包括“制作中”“已完成”“已取消”。已完成订单才会计入商家营业额。
- “我的”页无论是否扫码都可以打开，可查看昵称、头像和系统用户 ID，并修改个人资料。
- 普通用户在非本店管理员身份下不会看到本店管理入口。

### 5. 顾客注意事项

- 菜品图片或菜单首次加载需要网络；网络恢复后重新进入页面即可。
- 订单提交成功后不要反复点击提交。系统会尽量避免重复订单，但应以订单页实际记录为准。
- 未扫桌码却被提示不能下单，是堂食桌位校验正常生效，不是系统故障。
- 本版本暂不接入在线支付；请按店铺当前约定完成付款。

## 二、店铺管理员怎么使用

### 1. 进入自己的店铺

店铺一级管理员、二级管理员和超级管理员进入“我的”页后，可以从“我的店铺”进入已关联店铺；不需要每次扫描桌码。

进入店铺后，只有当前店铺确实有管理权限时才显示“管理入口”。在其他店铺中即使你在别的店是管理员，也会按普通用户显示和使用。

### 2. 日常订单处理

1. 打开管理入口中的订单管理。
2. 根据订单上的桌号、菜品、辣度和备注安排制作。
3. 制作完成后点击“确认完成”。订单会移到已完成，营业额和报表才会计入该订单。
4. 无法制作的“制作中”订单可取消，并填写取消原因。

注意：只有当天取消的订单才会恢复对应库存；不要为了修正账目随意修改已完成订单。

### 3. 菜品、分类和库存

- 新增或编辑菜品时，在同一页保存名称、价格、分类、图片、辣度、上下架状态和库存。
- 价格允许设置为 `0`，适合赠品或测试菜品。
- 下架优先级最高：下架后顾客看不到或不能购买；售罄用于临时卖完；库存用于每日可售数量控制。
- 删除菜品是永久操作。历史订单仍保留菜名、价格和规格快照，但菜品本身及其独有图片可能无法恢复。
- 分类删除前先确认没有需要保留的菜品归属。

### 4. 店铺营业与桌码

- 可在店铺设置中手动暂停/恢复接单，也可设置指定日期不营业。
- 暂停接单或不营业时，顾客可浏览和加购，但不能创建新订单。
- 桌码用于确认桌位，打印后可以长期张贴；不会自动刷新。
- 管理员主动重置店铺码或桌码后，旧码立即失效，必须重新打印或更换二维码。
- 新码可以查看数字码和二维码；历史旧码若只保存哈希，需重置后才能显示数字码。

### 5. 管理员权限边界

- **一级管理员**：管理本店菜单、订单、库存、设置，并可在本店授权二级管理员。
- **二级管理员**：协助管理本店日常业务，但不能继续授权其他管理员。
- **超级管理员**：跨店建店、跨店授权、全局用户和平台报表等操作只在 Web 超管后台完成。

不要把管理员账号给普通顾客使用，也不要在不属于自己的店铺中尝试管理数据。云函数会再次校验权限，前端入口隐藏只是方便使用，不是唯一安全措施。

## 三、店铺每天的建议流程

1. 营业前：检查接单开关、营业日期、桌码是否张贴、每日库存是否正确。
2. 营业中：按订单的桌号、辣度和备注制作；卖完及时售罄或下架。
3. 营业后：完成或取消仍在制作中的订单，核对已完成订单营业额。
4. 重要调整前：在 Web 超管后台下载店铺 JSON 备份，再批量调整菜单、桌位或权限。

## 四、出现问题先怎么处理

| 现象 | 先做什么 |
| --- | --- |
| 顾客看不到菜单 | 确认已扫码进入正确店铺；管理员检查店铺是否启用、菜品是否上架。 |
| 顾客无法提交订单 | 确认已扫本桌桌码、店铺正在接单、菜品未售罄且库存足够。 |
| 管理入口不见了 | 确认当前进入的是本人有管理权限的店；关闭并重新打开小程序刷新身份。 |
| 订单或库存看起来异常 | 先暂停接单、保留订单编号和截图，不要直接改数据库。 |
| Web 后台打不开 | 强制刷新浏览器；仍异常时查看部署与恢复手册。 |
